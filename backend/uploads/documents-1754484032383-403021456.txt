## 🧠 Project: **Lone Bot AI**

### 📝 Overview

**Lone Bot AI** is a lightweight, AI-powered document-based Q\&A system. It allows users to upload documents (PDFs, Excel, CSV), and ask questions based on the content. The system leverages NLP (Natural Language Processing) to extract relevant answers based on keyword + contextual understanding from the uploaded files.

This project is designed to be **modular**, so it can be embedded as a **component** in a larger AI system.
